# 2.4 — `SidecarSource` + recording state machine
status: in-progress
milestone: M2 · deps: 2.1, 2.3 · branch: task/2.4-sidecar-source

## Goal
The Node side of capture: spawn `oat-audio`, parse its framed stdout into `AudioFrame`s, control it over
stdin, and a recording state machine (idle → starting → recording ⇄ paused → stopping → idle, + error) that
the desktop main process will drive — testable entirely with the sidecar's `--synthetic` mode and FileSource.

## Context
SPEC §3, §8 (never silently stop; surface errors), D-8, D-16 (`native/oat-audio/PROTOCOL.md`), D-17.
`@oat/audio` (2.1): `AudioSource`, `AudioFrame`, FileSource. `native/oat-audio/scripts/check-frames.mjs`
(reference parser/validator — port to TS, keep it the contract).

## Scope
In:
- `@oat/audio/node` entry (Node-only, not imported by renderer code): `SidecarSource implements AudioSource`
  — locate binary (env `OAT_AUDIO_BIN`, dev path `native/oat-audio/.build/release/oat-audio`, packaged path
  later), spawn with args (sources, sample rate, `--synthetic` for tests, `--no-aec`), streaming frame parser
  (handles partial chunks, validates protocol version via `oat-audio version`), stdin commands, events
  (started/stopped/paused/resumed/error/device_changed/level/overrun/aec_unavailable) mapped to typed
  `AudioEvent`s, crash handling (unexpected exit → error event with stderr tail; optional auto-restart policy
  with backoff, keeping the shared clock continuous via an offset), graceful stop with timeout → SIGTERM → SIGKILL.
- `RecordingController` (pure TS state machine, source-agnostic): commands start/pause/resume/stop, emits
  state changes + frames + levels + errors; guards invalid transitions; tracks elapsed time; fans frames out
  to subscribers (STT, archive writer) without one slow subscriber blocking others (bounded per-subscriber
  queues with drop/overrun accounting).
- Tests: parser unit tests (chunk boundaries, bad magic/version, truncated frames); state machine tests;
  int test (`*.int.test.ts`, skipped automatically if the sidecar binary isn't built or not macOS) running
  `oat-audio capture --synthetic` for 2 s via SidecarSource → frame counts/timestamps match; pause/resume;
  stop; killing the child mid-run surfaces an error and (with restart policy) recovers.
- A `pnpm --filter @oat/audio build:sidecar` script that runs `swift build -c release` in native/oat-audio.
Out: Electron wiring (1.8/2.5), STT hookup (2.6), Opus archive (2.8). Never run non-synthetic capture.

## Acceptance criteria
- [ ] SidecarSource with `--synthetic` yields frames equivalent to FileSource's shape (same types, 16 kHz).
- [ ] Crash/restart and graceful-stop behaviours covered by tests.
- [ ] RecordingController slow-subscriber test: other subscriber unaffected.
- [ ] Global gates + `test:int` green on macOS.

pnpm install && pnpm --filter @oat/audio build:sidecar
