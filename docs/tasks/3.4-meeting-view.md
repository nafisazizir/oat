# 3.4 — Meeting note view (desktop + web)
status: in-progress
milestone: M3 · deps: 2.5, 2.6, 3.3 · branch: task/3.4-meeting-view

## Goal
The core screen: during and after a meeting, one view with the meeting header (title, time, attendees), my
notes editor, and a collapsible transcript panel — on desktop (live) and on web (synced).

## Context
SPEC §3 (Jot while transcribing), §4, D-20/D-26 (enhance on the doc), D-19/D-28 (desktop local store + sync),
`apps/desktop` (2.5 recording service + transcript panel; 2.6 local-store + SyncService; 1.8 bridge),
`apps/web` (document page with editor, enhance toolbar 4.4/4.5, chat panel 6.4, `?t=&seg=` reader,
`server/transcript.ts`), `@oat/editor`, `@oat/calendar` (CalendarEvent attendees), `@oat/ui`.

## Scope
In:
- Desktop: the recording view becomes a meeting note: header (editable title, start time, duration, attendees
  chips from calendar or manual add), `OatEditor` for my notes (stored in local-store `document.content_json`,
  synced by 2.6; autosave), transcript panel on the right (2.5 component) collapsible, resizable; "New meeting
  note" starts a meeting doc + recording; past meetings list in the desktop sidebar (from local store); open a
  past meeting → editor + stored transcript (read from local store).
- Web: document page for `kind: meeting` shows the same header + collapsible transcript panel (server
  segments, virtualised, me/them, click → jump target for future playback (3.7)); `?t=` reader integrates with
  this panel; participants editable (add/remove manual participants) via API with authz + deny markers.
- Shared components where sensible (`@oat/ui` or a new `packages/meeting-ui`) — avoid duplicating the
  transcript list between desktop and web.
- Tests: desktop e2e (fixture recording → type notes during recording → stop → notes + transcript persisted
  locally and synced to Postgres → open on web shows both); web e2e (meeting header, participants edit,
  transcript panel collapse/resize, deep link); screenshots desktop + web light/dark.
Out: audio playback (3.7), detection-triggered start (7.3), enhance UI changes (exist).

## Acceptance criteria
- [ ] Jot during a fixture recording on desktop; notes + transcript visible on web after sync.
- [ ] `pnpm run ci` green.
