# 3.7 — Audio playback in the meeting view (desktop)
status: todo
milestone: M3 · deps: 2.8, 3.4, 3.8 · branch: task/3.7-playback

## Goal
Listen back: play a meeting's local audio (mic, system or mixed) with the transcript in sync — click a segment to
jump there, the playing segment highlights — and clear states when audio isn't on this Mac.

## Context
SPEC §4 Audio archive, D-10, D-24 (multi-part, meeting clock offsets), `@oat/audio` (readMeetingRange,
locateMeetingTime/meetingSeek, Ogg Opus), `packages/meeting-ui` (shared transcript list), `apps/desktop` meeting
view (3.4) + storage status channel from 3.8 ("Audio deleted" / "Audio on another device"), web meeting view.

## Scope
In:
- Desktop main: serve audio to the renderer safely — a custom `oat-audio://<meetingId>/<part>/<source>` protocol
  (or a decode-to-PCM bridge stream) with path validation inside the audio root, range requests for seeking;
  mixed track = mic+system mixed on the fly (or decode both and mix in the renderer via WebAudio — pick, justify,
  measure CPU).
- Player UI in the meeting view: play/pause, scrubber across the whole meeting clock (parts + gaps rendered),
  speed 1×/1.25×/1.5×/2×, source toggle (Me / Them / Both), keyboard (space, ←/→ 5 s), current time.
- Sync: clicking a transcript segment seeks to its `startMs` (via meetingSeek across parts); the segment under
  the playhead highlights and auto-scrolls (respecting user scroll like the live panel).
- States: no audio ("Audio deleted" / "Audio is on <device>" from 3.8 status), partial recordings, loading/error.
- Web: transcript segments show "Audio on <device name>" hint (device name from sync metadata if available),
  no player.
- Tests: unit (seek mapping across parts and gaps, highlight logic), desktop e2e with a fixture recording (two
  parts): click segment → player time ≈ startMs ± 100 ms; playing advances highlight; deleted audio → state.
  Screenshots.

## Acceptance criteria
- [ ] Click-to-seek and playhead highlight work across multi-part recordings; states correct.
- [ ] `pnpm run ci` green.
