# 1.3 — `packages/ui`: tokens, theme, base components
status: done
milestone: M1 · deps: 1.1 · branch: task/1.3-ui-tokens

## Goal
Our design foundation (D-6): shadcn/ui components + Tailwind v4 with **every** colour/type/radius/spacing/
motion value as a CSS-variable token, light + dark, shared by apps/web and apps/desktop.

## Context
SPEC §5 (UI), D-6. Visual identity is ours — not Granola's. Direction: calm, warm, paper-like workspace
(think oat/cream neutrals, one confident accent, generous whitespace, crisp type); dense where it matters
(sidebar, transcript). Must look good in both themes. Use the `shadcn` skill if available.

## Scope
In:
- `packages/ui` (`@oat/ui`): Tailwind v4 setup exported as `@oat/ui/styles.css` (tokens + base layer),
  `tokens.css` with semantic tokens (background/foreground/muted/accent/primary/destructive/border/ring/
  sidebar-*, plus app-specific: `--me` / `--them` transcript colours, `--ai-text` vs `--my-text` for
  enhanced notes), typography scale, radius, spacing, shadows, motion durations/easings; `.dark` overrides.
- shadcn components (source in the package, imported as `@oat/ui/components/<name>`): button, input,
  textarea, label, dialog, sheet, dropdown-menu, popover, tooltip, command, select, switch, tabs, separator,
  scroll-area, avatar, badge, card, skeleton, sonner (toast), sidebar, resizable. `cn()` util.
- A gallery: `packages/ui/gallery` small Vite app (`pnpm --filter @oat/ui gallery`) showing tokens + every
  component in light and dark — used for screenshots and the later design pass.
- Tests: a render test per a few key components (vitest + @testing-library/react + jsdom), token file
  sanity test (every token used in components exists in both themes).
- Design notes: palette rationale, type scale, a short "how to restyle" guide (change tokens only).
Out: app layouts (1.4), editor styles (3.1).

## Design notes

### What's in the package
- `src/tokens.css`: every raw value (colour, type, radius, spacing, layout widths, elevation, motion).
  `:root` is light and `.dark` is dark. Only colour and elevation tokens change in dark.
- `src/styles.css` (`@oat/ui/styles.css`): Tailwind v4 + `tw-animate-css` + `shadcn/tailwind.css`
  (data-state variants), self-hosted variable fonts (`@fontsource-variable/*`, no CDN), the tokens, an
  `@theme inline` block that maps tokens to Tailwind names (`--color-primary: var(--primary)`,
  `--text-sm: var(--type-sm)`, `--spacing: var(--space)`, `--shadow-md: var(--elevation-md)`, …), and the
  base layer (body font and colours, serif h1–h3, `::selection`, reduced motion). `@source './'` makes the
  consumer's Tailwind scan this package's sources.
- Components: shadcn CLI, style `radix-nova` (Radix primitives, lucide icons), in `src/components/*.tsx`,
  imported as `@oat/ui/components/<name>`. All 22 requested components, plus `input-group` (used by `command`)
  and `hooks/use-mobile` (used by `sidebar`). `cn()` lives in `src/lib/utils.ts` (re-exports the `cn` package,
  shadcn's clsx + tailwind-merge replacement); every component imports it from there.
- Local changes to the stock shadcn output, all toward "tokens only":
  `bg-black/10` scrim → `bg-overlay` (dialog, sheet); sidebar widths → `var(--sidebar-width-*)`;
  card, dialog and sheet titles → `font-heading text-lg`; `use-mobile` rewritten with
  `useSyncExternalStore` (lint: no setState in effect).
- `package.json` exports add `./styles.css`, `./tokens.css`, `./components/*` (.tsx), `./hooks/*`,
  `./lib/*`, in line with D-15 (TS-source package). `react`, `react-dom` and `tailwindcss` (^4) are peer deps (the consumer's compiler owns Tailwind). `shadcn` is a devDep: we use its CLI, and `styles.css` imports its `shadcn/tailwind.css`, which resolves from the workspace install.
  `components.json` is set up so `pnpm dlx shadcn@latest add <name>` (run in `packages/ui`) writes into
  `src/components` with `@oat/ui/...` imports. After adding a component, rewrite `from "cn"` →
  `from "@oat/ui/lib/utils"` and run `pnpm format`.

### Palette rationale: "oat paper + ink"
- **Surfaces** are warm cream neutrals: hue ≈ 80, chroma ≤ 0.016, and never pure white.
  `--background` (L 0.982) is the page. `--card`/`--popover` are a slightly brighter "fresh sheet". The
  sidebar is a shade deeper, like a desk blotter. Hover (`--accent`) and muted fills step down in small
  amounts, so the UI stays calm.
- **Text** is a warm brown-black ink (L 0.245, hue 62), never pure black. `--muted-foreground`
  (L 0.505) stays above 4.5:1 on the page.
- **One confident accent: ink blue** (`--primary`, oklch 0.43 0.125 262), like a fountain pen on paper.
  It's used for primary actions, focus ring, selection, and the "me" voice. It was chosen to keep us away
  from Granola's look (we don't use green and don't borrow their accent) and to stay calm next to the warm
  neutrals.
- **Status colours** are muted and warm (brick, sage-green, honey) and used sparingly.
- **App tokens:** `--me` is an ink-tinted bubble and `--them` an oat bubble, so the two transcript voices
  are easy to tell apart without loud colour. `--my-text` = full-strength ink and `--ai-text` = softer
  slate ink (hue 255), so in enhanced notes your own words stand out and AI additions recede but stay
  readable (about 6:1).
- **Dark mode is "espresso":** warm charcoal (L 0.195, hue 68), cream text, a lighter ink accent
  (L 0.74) with dark text on it. Borders and inputs are cream at 10–15% alpha so they work on every surface.
  Shadows get deeper and gain a faint cream hairline, because a plain shadow doesn't show up on a dark
  background.
- Elevation is low and diffuse with a warm shadow colour (paper on a desk), not grey drop shadows.

### Type scale
- Fonts: **Instrument Sans** (UI, a crisp grotesk), **Newsreader** (titles and headings via
  `--font-family-heading`, with an optical-size axis; this gives the paper feel), and **Geist Mono**.
  All are self-hosted variable fonts bundled by the consumer, with system fallbacks.
- Scale ≈ 1.2 ratio around a 15px body. 13px is the dense UI default (`body` is `text-sm`).
  | name | size / line-height | use |
  |---|---|---|
  | xs | 12 / 16 | captions, timestamps |
  | sm | 13 / 20 | UI default: menus, sidebar, buttons, transcript |
  | base | 15 / 24 | notes body |
  | lg | 17 / 26 | lead, card/dialog titles |
  | xl | 20 / 28 | note section headings |
  | 2xl | 24 / 32 | headings |
  | 3xl | 30 / 36 | note title |
  | 4xl | 38 / 44 | display |
- We keep Tailwind's stock size names (`text-sm` …) on purpose, with token-driven values. A custom
  `text-<name>` size would be mis-merged as a colour by `cn()`/tailwind-merge (a unit test covers this).
- Headings use `--tracking-heading` (−0.012em) and `text-wrap: balance`. Paragraphs use `pretty`.

### Radius, spacing, motion
- Radius has a single knob, `--radius` (0.5rem). `rounded-sm…4xl` are multiples of it.
- Spacing: `--space` (0.25rem) is Tailwind's spacing unit (`p-4` = 4 × `--space`). Layout tokens are
  `--content-width` (44rem note measure, `max-w-content`) and `--sidebar-width-{default,mobile,collapsed}`.
- Motion: `--duration-{fast,base,slow}` (100/160/260ms) and `--easing-{standard,enter,exit}`. Every
  `transition-*` utility defaults to `--duration-base` + `--easing-standard`. `duration-fast|base|slow` and
  `ease-standard|enter|exit` utilities exist. `prefers-reduced-motion` collapses animations.

### How to restyle (tokens only)
1. Edit `packages/ui/src/tokens.css`: change the value in `:root` and again in `.dark`. Don't touch
   component sources.
   - Change the accent: `--primary`, `--ring`, `--selection`, `--me*`, `--chart-1`.
   - Warmer or cooler paper: change the hue (third number) of the surface tokens in both blocks.
   - Rounder or sharper: `--radius`. Denser or airier: `--space` and the `--type-*` pairs.
   - Sans headings: `--font-family-heading: var(--font-family-sans)`.
   - New font: add an `@fontsource-variable/*` dependency, import it in `styles.css`, and point the
     `--font-family-*` token at it.
2. New semantic colour: add it to both blocks in `tokens.css`, then map `--color-<name>: var(--<name>)` in
   `styles.css` `@theme inline`. `tokens.test.ts` fails if it's missing from either theme.
3. Run `pnpm --filter @oat/ui gallery` (http://localhost:5199; `?theme=dark`, `?static=1` pins overlays
   open) and `pnpm --filter @oat/ui screenshots` to re-capture the evidence.

### Tests
- `src/tokens.test.ts` checks:
  - every colour token exists in light and dark, and dark adds no extra ones;
  - every Tailwind colour maps to a token defined in both themes, and every theme mapping resolves;
  - the app tokens are present;
  - component sources contain no colour literals and no Tailwind default-palette colours;
  - every colour utility used in components (`bg-*`, `text-*`, `border-*`, …) is a token;
  - every `var(--x)` in components is a token, a theme value or set inline (I checked that it fails on a
    probe file).
- `src/components.test.tsx` covers `cn`, Button (variants and asChild), Dialog (open, accessible title,
  close), Switch, Tabs, Command filtering and Sidebar collapse, using jsdom + Testing Library. Stubs for
  ResizeObserver and matchMedia are in `src/test-setup.ts`.

Findings (must fix):
1. **Motion, type and radius values bypass tokens in components.** This breaks the Goal ("every … motion value as a token")
   and the "How to restyle" guide. Motion: `duration-100` at `dialog.tsx:32,54`, `sheet.tsx:34`, `popover.tsx:26`,
   `select.tsx:63`, `dropdown-menu.tsx:37,225`; `duration-200 ease-in-out` at `sheet.tsx:59`;
   `duration-200 ease-linear` at `sidebar.tsx:213,225,387`; `ease-linear` at `sidebar.tsx:280`. Type: `text-[0.8rem]` at
   `button.tsx:26`, which is off-scale. Radius: `rounded-[min(var(--radius-md),10px|12px)]` at `button.tsx:25,26,30,32` and
   `select.tsx:37` caps the `--radius` knob.
   Fix: use `duration-fast|base|slow` and `ease-standard|enter|exit`, `text-xs`, and plain `rounded-md`. Then extend
   `tokens.test.ts` to reject `duration-\d`, `ease-(linear|in|out|in-out)\b` and `text-\[` in component sources.
2. **AA text contrast failures in light theme.**
   - Destructive text on its tint fails. `text-destructive` on `bg-destructive/10` measures 4.28:1, and about 3.9:1 on the
     `/20` hover. Affected: `button.tsx:19`, `badge.tsx:14`, the `dropdown-menu.tsx:65` destructive item. Fix: darken the
     light `--destructive` to about L 0.50 in `tokens.css` so that rest and hover both reach at least 4.5:1.
   - Inactive tab labels fail. `text-foreground/60` on `bg-muted` measures 4.13:1 (`tabs.tsx:56`). Fix: use
     `text-muted-foreground`, which measures 5.1:1.
3. **`sidebar.tsx:28,91-100`: the global Cmd/Ctrl+B handler calls `preventDefault()` on every keydown.** It will take the
   Bold shortcut from the TipTap editor (3.1) and from any text field. Fix: ignore events whose target is editable
   (`input`, `textarea`, `[contenteditable]`, `isContentEditable`), or make the shortcut an opt-in prop with no default.
   Add a test for it.

Optional (nits):
