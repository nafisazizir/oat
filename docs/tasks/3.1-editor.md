# 3.1 — `packages/editor`: TipTap block editor
status: in-progress
milestone: M3 · deps: 1.3 · branch: task/3.1-editor

## Goal
A Notion-like block editor component reused by web and desktop, with TipTap/ProseMirror JSON as the canonical
format (D-4).

## Context
SPEC §4 Editor row, §7 (my text vs AI text marking), D-4. Tokens from `@oat/ui` (`--my-text`, `--ai-text`).
Research: Granola also uses TipTap/ProseMirror (bundle-map.md) — no code reuse, behaviour only.

## Scope
In:
- `packages/editor` (`@oat/editor`): `<OatEditor value onChange editable placeholder />` React component
  (TipTap v3 latest), schema/extension set exported separately (`createExtensions(options)`) so server code can
  use the same schema headlessly (`@tiptap/core` / `@tiptap/html` / generateJSON in Node).
- Blocks: paragraph, headings 1–3, bullet/ordered lists, task list (checklist), blockquote, code block,
  horizontal rule, callout (custom node with emoji/variant), link (autolink + paste), mention (`@person`,
  suggestion list fed by a prop callback), hard break. Marks: bold, italic, strike, code, highlight, link.
- Every block node carries a stable `id` attribute (unique-id extension) — needed for citations (6.x) and
  enhancement diffing. Custom attribute `origin: 'me' | 'ai'` on block nodes, rendered with `--my-text` /
  `--ai-text` styles (AI blocks visually distinct, per SPEC §3.5).
- Slash menu (`/` → filterable list of blocks, keyboard nav), Markdown input rules/shortcuts (`# `, `- `, `[] `,
  `> `, ``` ``` ```, `---`), bubble menu for marks + link editing. Placeholder text per empty block.
- Styles via `@oat/ui` tokens only (prose styles in `packages/editor/src/styles.css`).
- Tests: schema tests in Node (create doc JSON, validate, ids assigned), component tests (jsdom) for slash
  menu filtering and input rules where feasible. A gallery/playground route: add an "Editor" page to the
  `@oat/ui` gallery or a small Vite playground in this package; Playwright screenshot to
  `docs/tasks/evidence/3.1/`.
Out: Markdown conversion (3.2), persistence/sync (3.3/3.5), collaboration (non-goal).

## Acceptance criteria
- [ ] All listed blocks/marks work via slash menu and Markdown shortcuts (Playwright test types them).
- [ ] Every block has a unique `id`; `origin` attribute round-trips through JSON.
- [ ] Headless schema usable in Node (test).
- [ ] Global gates green; screenshot evidence.
