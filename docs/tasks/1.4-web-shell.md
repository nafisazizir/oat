# 1.4 — `apps/web`: Next.js shell + app layout
status: todo
milestone: M1 · deps: 1.3 · branch: task/1.4-web-shell

## Goal
The web app skeleton every web feature plugs into: Next.js App Router with the Oat app layout (sidebar with
workspace switcher + page tree placeholder, content area), built on `@oat/ui`, with Playwright e2e wired up.

## Context
SPEC §4–5, D-6, D-15 (TS-source packages → `transpilePackages`). Use the `vercel:nextjs` skill for current
Next.js App Router guidance (verify current stable major with `pnpm view next version`). UI tokens/components
from `@oat/ui` (1.3) — do not invent colours. Research: `research/granola/bundle-map.md` (layout inspiration
only — single main window, sidebar + content; visual identity is ours).

## Scope
In:
- `apps/web` (`@oat/web`): Next.js (latest stable), React 19, Tailwind v4 via `@oat/ui/styles.css`,
  `transpilePackages: ['@oat/*']`, typed env module (zod) reading `.env` (D-11 vars; app must boot with only
  the `.env.example` defaults).
- Routes (placeholders with real layout, data mocked in-memory for now): `/` (redirect to `/home`),
  `(app)/home` (recent notes list empty state), `(app)/d/[docId]` (document page placeholder),
  `(app)/settings`, `(auth)/sign-in` (form UI only; wiring in 1.6), `share/[token]` (public layout, 5.4).
- App layout: collapsible sidebar (workspace switcher dropdown, "New note" button, search trigger, sections:
  Home / Shared / Private tree placeholder / Templates / Settings), top bar with breadcrumbs, content area;
  keyboard shortcut `⌘K` opens a command palette (shadcn Command) with a few nav actions; light/dark/system
  theme toggle (next-themes or equivalent, no flash).
- Empty, loading (`loading.tsx` skeletons) and error (`error.tsx`) states for app routes.
- `GET /api/health` → `{ ok: true, version }`.
- Playwright config in apps/web (`pnpm --filter @oat/web e2e`) starting `next dev` on port 3000; smoke tests:
  home renders, sidebar collapses, ⌘K palette navigates, theme toggles. Screenshots (light/dark) → 
  `docs/tasks/evidence/1.4/`.
Out: auth (1.6), DB access (1.5/3.3), Dockerfile (1.9), real document data.

## Acceptance criteria
- [ ] `pnpm --filter @oat/web dev` serves on :3000 with no runtime errors; `next build` succeeds.
- [ ] Playwright smoke suite passes; screenshots saved and look polished in both themes.
- [ ] No hard-coded colours outside `@oat/ui` tokens.
- [ ] Global gates green.
