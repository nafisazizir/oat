# 2.5 — Desktop recording + live transcript panel
status: todo
milestone: M2 · deps: 1.8, 2.2, 2.4, 2.8 · branch: task/2.5-transcript-panel

## Goal
In the desktop app: start/pause/stop a recording, see live two-source transcript (me/them) with interim →
final updates, levels and status — wired through the real pipeline (SidecarSource or FileSource →
RecordingController → DeepgramProvider ×2 (mock in dev) + OpusArchiveWriter).

## Context
SPEC §3, §8 (latency, never silently stop), D-17, D-19 (stable segment ids; finals replace interims;
retraction = final with empty text), D-24. `@oat/audio` (RecordingController, SidecarSource, FileSource,
RecordingArchive), `@oat/stt` (DeepgramProvider; token via `getToken` → our API's STT grant endpoint — add
`POST /api/stt/token` in apps/web returning a short-lived token from the mocks grant endpoint in dev /
Deepgram in prod, session-authenticated), `apps/desktop` (1.8: bridge contract, main-owned store, windows).
UI tokens `--me/--them`.

## Scope
In:
- Main process `RecordingService`: owns the controller, STT streams per source, archive; exposes bridge
  channels: `recording:start {meetingId?, source: 'sidecar'|'file', fixture?}`, `pause`, `resume`, `stop`,
  subscription `recording:state` (state, elapsed, levels, per-source STT status, errors) and
  `transcript:segments` (batched deltas). Dev menu/env to use FileSource fixtures instead of the mic
  (`OAT_AUDIO_SOURCE=file:standup-short`) — the default in e2e.
- Renderer: recording bar (start/pause/stop, elapsed, level meters, STT status pill, error banner that never
  hides), transcript panel (virtualised list, me/them labels + colours, interim italic/muted then final,
  autoscroll with "jump to live" when the user scrolls up, timestamps), empty/loading/error states. Widget
  window shows compact status + stop.
- Tests: unit (segment store: interim/final/retraction merge by id; batching), Playwright `_electron` e2e with
  FileSource `standup-short` in fast/realtime + mock STT: segments for both sources appear, finals match
  ground-truth text closely (mock_fixture), pause/resume, stop → archive files exist. Screenshot evidence.
Out: persistence to SQLite/API (2.6), meeting note editor (3.4), playback (3.7).

## Acceptance criteria
- [ ] E2E: fixture meeting → live transcript in the panel with me/them; latency to first interim < 1.5 s.
- [ ] Errors (STT down) visible and recording continues (archive keeps writing).
- [ ] `pnpm run ci` green.
