# 6.1 — Chunking + embeddings (pgvector) + indexing queue
status: todo
milestone: M6 · deps: 3.3, 4.1, 2.6 · branch: task/6.1-embeddings

## Goal
Everything a user can read is retrievable by meaning: notes and transcripts chunked with stable references
(block ids, segment ids + start_ms), embedded, stored in pgvector, kept fresh incrementally via a Redis-backed
job queue.

## Context
SPEC §6 `chunk`, D-11 (Redis in compose), D-19/D-22 (change_log drives incremental indexing),
`@oat/ai` (getEmbeddingModel, EMBEDDING_DIMENSIONS, mock embeddings with similarity property), `@oat/db`
(chunk table + HNSW cosine index; note reviewer's tip: filtered HNSW + `iterative_scan` for small workspaces),
`@oat/editor/markdown`, `@oat/core` permissions.

## Scope
In:
- Chunkers: notes → chunks by heading/section with block-id ranges (~300–500 tokens, overlap); transcripts →
  windows of consecutive segments (by time ~60–90 s / token budget) with segment-id range + start/end ms + source.
- Queue: BullMQ (or a minimal Redis list/stream worker — justify) `index-document` / `index-meeting` jobs,
  debounced per document, retries with backoff, idempotent (content hash per chunk; unchanged chunks keep
  embeddings). Worker entry runnable in-process in dev (`apps/web` instrumentation or a `pnpm worker` script —
  and a compose `worker` service in the `app` profile).
- Triggers: on document/segment writes (from change_log polling or direct enqueue in write paths — pick, note).
  Backfill script `pnpm --filter @oat/db index:backfill`.
- `searchChunks(ctx, query, {k, scope: {documentId?|workspace}})` → permission-filtered (SQL) hybrid ranking
  (vector cosine + FTS rank from 3.6 if merged, else vector only) returning references for citations.
- Tests: chunker unit tests (boundaries, refs), queue int (enqueue → embedded rows; unchanged content not
  re-embedded; deletes remove chunks), retrieval int (permission-safe across users/workspaces; relevant
  fixture chunk ranks top-3 with mock embeddings).
Out: chat tools/API/UI (6.2–6.4).

## Acceptance criteria
- [ ] Writes → chunks indexed within seconds in dev; backfill works; retrieval permission-safe.
- [ ] `pnpm run ci` green.
