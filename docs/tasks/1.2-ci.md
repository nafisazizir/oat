# 1.2 — CI: `pnpm run ci` + GitHub Actions workflow
status: in-progress
milestone: M1 · deps: 1.1, 1.10 · branch: task/1.2-ci

## Goal
One command that runs every gate the factory relies on, identically on a laptop and in CI (D-12: no remote
yet — the workflow file must be correct so pushing to GitHub later "just works").

## Context
FACTORY §3 gates, D-11 (compose stack, ports), D-12, `docs/DEV.md`, root scripts (`scripts/dev.mjs`),
turbo.json. Packages with e2e (`@oat/web`, `@oat/editor`, `@oat/ui` screenshots) and Swift (`native/oat-audio`).

## Scope
In:
- Root `ci` script (`scripts/ci.mjs`, Node, no shell-isms): format:check → typecheck → lint → test → ensure
  stack (`dev:up`, build images only if missing) → db migrate on a throwaway DB check → test:int → e2e
  (Playwright, each package on its own free port) → on macOS also `swift build` + `swift test` + synthetic
  check-frames for `native/oat-audio`. Flags: `--fast` (skip int/e2e/swift), `--only <step>`. Prints a summary
  table with durations; non-zero exit on any failure.
- `.github/workflows/ci.yml`: ubuntu job (pnpm cache, Playwright browsers cache, services via `docker compose`
  — or GitHub service containers mirroring D-11 — running `pnpm run ci` minus swift) + macos job for the Swift
  sidecar (build/test/synthetic). Pin action versions by tag. Concurrency cancel-in-progress. No secrets needed.
- Validate the workflow locally: `actionlint` via docker (`rhysd/actionlint` image) if available, else a YAML
  schema check; document.
- Update FACTORY §3/§9 and DEV.md to say "`pnpm run ci` is the gate".
Out: release/signing workflows (9.1), Vercel deploys (9.6).

## Acceptance criteria
- [ ] `pnpm run ci` passes on main locally (record timings) and fails when a deliberate test failure is
      introduced (then reverted).
- [ ] Workflow passes actionlint.
- [ ] Global gates green.

## Verification
```
pnpm install && pnpm run ci
docker run --rm -v "$PWD":/repo -w /repo rhysd/actionlint:latest -color
```
