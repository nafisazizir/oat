## Design notes
(implementer, 2026-11-14)

**Files**: `scripts/ci.mjs` (new), `.github/workflows/ci.yml` (new), root `package.json` (`ci` → `node
scripts/ci.mjs`; `lint` → `turbo run lint && eslint scripts` so root scripts are linted too), FACTORY §3/§9,
DEV.md ("CI" section + one line under Tests).

**`scripts/ci.mjs`** — plain Node, no deps, `spawn` with argv arrays (no shell). Steps in order:
`format → actionlint → typecheck → lint → test → stack → migrate → test:int → e2e → swift:build → swift:test →
swift:synthetic`. Each step calls the root `pnpm` scripts, so they stay the single source of truth.
- Failure policy: run every independent step (agents see all failures at once); a step whose `needs` failed is
  `skip` (`migrate`/`test:int`/`e2e` need `stack`; `swift:test`/`swift:synthetic` need `swift:build`).
  `--bail` stops at the first failure. Summary table with per-step and total durations; exit 1 on any FAIL,
  2 on bad args.
- Flags: `--fast` (format…test only), `--only a,b` (step names or group `swift`; no implicit prerequisites),
  `--bail`, `--list`. A bare `--` is ignored so `pnpm run ci -- --fast` also works.
- `stack`: reads `docker compose config --services` + `docker compose ps --format json` (handles NDJSON and
  the older array form); if every service is `running` + `healthy` it does nothing at all. Otherwise it runs
  `node scripts/dev.mjs up` (`up -d --wait`, builds images only if missing). Never down/reset/build.
  Verified: container `CreatedAt` unchanged across runs.
- `migrate`: creates `oat_test_<base36 ms>_<hex>` (testkit's naming, so a leak is swept by the next
  `createTestDatabase()`), via `docker compose exec -T postgres psql` (no host psql needed); runs
  `pnpm --filter @oat/db db:migrate` twice with `DATABASE_URL` pointing at it (exported env wins over `.env`);
  asserts `count(drizzle.__drizzle_migrations)` = `_journal.json` entries; drops `WITH (FORCE)` in `finally`.
  Checked the database is gone afterwards.
- `e2e`: discovers packages with an `e2e` script via `pnpm m ls --json --depth=-1`; runs them one at a time,
  each with `E2E_PORT=<free port>` (bind :0 on 127.0.0.1, close, reuse). `skip` while none exist (today: no
  package has one; `@oat/ui` screenshots/`@oat/web`/`@oat/editor` should add `e2e` scripts that honour
  `E2E_PORT` — follow-up for those tasks, outside this task's file scope). Mechanism tested by temporarily
  adding `e2e` scripts to ui (exit 0) and editor (exit 1): distinct ports passed, step FAILed naming
  `@oat/editor`; reverted.
- `swift:*`: macOS only (`skip` elsewhere). Synthetic check pipes `<bin>/oat-audio capture --synthetic
  --duration 2` into `node scripts/check-frames.mjs --expect-seconds 2` in Node (no shell), 60 s kill timeout.
  Never runs real capture.
- `actionlint`: pinned `rhysd/actionlint:1.7.12`; each workflow is fed on **stdin** (`-stdin-filename`) instead
  of bind-mounting the repo, because Docker Desktop on this machine can't share `~/Documents` (the task's
  Verification command fails here with `mkdir /host_mnt/...: operation not permitted`). Skips if Docker is
  missing. Proven to catch errors: an unknown runner label and a misspelt `steps.<id>` both FAILed the step.

**Workflow** (`.github/workflows/ci.yml`): `push` to main, `pull_request`, `workflow_dispatch`; concurrency
`ci-<workflow>-<ref>` with cancel-in-progress; `permissions: contents: read`; no secrets.
- `checks` (ubuntu-24.04, 30 min): checkout@v5, pnpm/action-setup@v4 (version from `packageManager`),
  setup-node@v5 (`.nvmrc`, pnpm cache), `pnpm install --frozen-lockfile`, cache `~/.cache/ms-playwright`
  (key = lockfile hash; on hit only `playwright install-deps`), `pnpm run ci` (stack step builds + starts compose
  on the runner — chosen over service containers so CI = local exactly; Swift steps `skip`). On failure: dump
  `docker compose ps/logs` and upload Playwright reports.
- `swift` (macos-26 → Xcode 26 / Swift 6.2 per the sidecar README): checkout, setup-node, `node scripts/ci.mjs
  --only swift` (no pnpm install needed).
- Not exercised on real runners (no remote, D-12) — first push should be watched.
