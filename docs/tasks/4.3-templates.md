# 4.3 — Templates + `buildMeetingContext()`
status: todo
milestone: M4 · deps: 3.3, 4.1, 4.2 · branch: task/4.3-templates

## Goal
Templates drive enhancement (D-20): title, description, ordered sections {heading, instructions}. Five
built-ins we write ourselves, custom templates per workspace with an editor, and one shared context builder.

## Context
SPEC §4 Enhance, §6 `template`, §7, D-20, `@oat/ai` (enhance contract + EnhanceFn from 4.2, evals with
eval-only templates — reconcile: built-ins live in `@oat/ai/templates` and evals use them), `@oat/editor/markdown`
(toMarkdown with blockIds/includeOrigin for notes), `@oat/db` template table, `apps/web` (settings, routes),
`research/granola/enhance-chat.md` (behaviour reference only — write all wording ourselves).

## Scope
In:
- `@oat/ai/templates`: zod schema; 5 built-ins (General, 1:1, Sales/discovery, Standup, Interview) with
  sections + instructions in our own words; stable ids; seeded into DB as `is_builtin` (idempotent seed/upsert).
- `buildMeetingContext({ meeting, attendees, notesDoc, segments, aboutMe?, locale, vocabulary? })` →
  structured context (notes Markdown with block ids, speaker-labelled transcript with segment ids + start_ms,
  colleagues vs externals by email domain, meta) + token budgeting (truncate transcript middle-out with
  markers when over budget; section budget scales with transcript length). Pure + unit tested.
- `apps/web`: `/templates` list (built-in + workspace custom), editor (title, description, sections drag
  reorder, add/remove, instructions textarea, preview), duplicate built-in → custom; API routes with
  `@oat/core` checks (members create/edit in workspace; viewers read-only).
- Evals: switch 4.2 fixtures to the real built-ins; baseline update justified in Design notes.
- Tests: schema/context unit tests, API int tests (authz), e2e: create custom template from built-in,
  reorder sections, save. Screenshots.
Out: enhance pipeline (4.4), auto-pick template (IDEAS).

## Acceptance criteria
- [ ] 5 built-ins seeded; custom template CRUD works with authz; `buildMeetingContext` tested.
- [ ] `pnpm --filter @oat/ai eval` passes with built-ins; `pnpm run ci` green.
