# 9.4 — End-to-end acceptance script (compose stack)
status: in-progress
milestone: M9 · deps: M1–M8 · branch: task/9.4-acceptance

## Goal
One script proves v1 works end to end on a clean machine with only Docker + Node + pnpm (D-11): sign up →
record a fixture meeting on desktop → transcript live → stop → post-meeting pipeline enhances → share via link →
teammate invited sees it → chat answers with citations → Notion (mock) receives the page → search finds it →
playback seeks. Runs in CI as its own step.

## Context
SPEC §9, PLAN 9.4, D-11, every feature task's e2e helpers (apps/web/e2e, apps/desktop/e2e), `scripts/ci.mjs`.

## Scope
In:
- `e2e/acceptance/` (new workspace package or under apps/desktop/e2e) driving Electron + a web browser context +
  a second user (teammate) with Playwright, against the compose stack and in-process mocks, fixture audio.
- A "fresh clone" check: script (`scripts/acceptance-fresh.mjs`) that clones the repo to a temp dir, runs
  `pnpm i && pnpm dev:up && pnpm run ci --only acceptance` there (uses the running compose stack), proving no
  hidden local state. Documented in DEV.md ("Proving it works on a new machine").
- Record timings vs SPEC §8 quality bars (interim latency, enhance time with mock, cold start) in the evidence.
- CI step `acceptance` after e2e.
Out: real providers (9.6), signing (9.1).

- [ ] Acceptance script passes locally and from a fresh clone; CI step added; timings recorded.
