## Goal
How do Granola's post-meeting enhancement and chat work from the client's perspective: what inputs are
gathered (notes, transcript, template, attendees, user profile), when enhancement triggers, request/stream
shape (structured vs text, how the result streams into the editor, how "my notes" vs AI text is
distinguished), templates model, regenerate/undo, chat scoping + citations. **Not their prompts.**

  warning, no undo. Chat = typed view-context scopes, JSON event stream, per-line citations with lazily
  fetched quotes (no transcript timestamp). Note edit/rewrite tools are applied client-side.
