## Design notes
(designer + implementer, 2026-11-15)

**Method.** `e2e/design-sweep.spec.ts` signs up a fresh user, seeds realistic content (`e2e/sweep-helpers.ts`:
a rich page shared by link, a recorded meeting with 2 attendees + 16 transcript lines + action items, a folder)
and screenshots 29 routes/states × light/dark × 1440/390 px (full page; empty states first, then populated,
plus overlays: ⌘K, mobile sidebar, share dialog, assistant panel). `before/` = `main` at the start (114 images),
`after/` = this branch (118: + folder page). The axe scan (`e2e/a11y.spec.ts`, `@axe-core/playwright` 4.14,
tags WCAG 2.0/2.1/2.2 A+AA + best-practice) runs in CI. Token contrast was already tested (1.3); axe found no
contrast issue in either theme.

**Punch list** (✅ fixed · 🎫 ticketed):
