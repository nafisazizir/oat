# 2.8 — Local audio archive (Ogg Opus)
status: todo
milestone: M2 · deps: 2.4 · branch: task/2.8-audio-archive

## Goal
Every recording is archived locally per meeting and source as Ogg Opus, written incrementally so a crash
keeps everything up to the last flush (D-10, SPEC §6), on the same clock as transcript segments.

## Context
SPEC §4 Audio archive, §6 desktop-only `audio_recording`, D-10, D-17 (archive backfill later in 2.9),
`@oat/audio` (AudioFrame, events incl. overrun/format_changed, RecordingController from 2.4).

## Scope
In:
- `@oat/audio/node` `OpusArchiveWriter`: per source, mono 16 kHz → Opus (~24 kbps, 20 ms frames) in Ogg pages,
  flushed at least every ~1–2 s (fsync policy documented); correct granule positions; gaps (overrun/pause)
  handled so archive time stays aligned with the recording clock (insert silence or record a gap map — pick
  and justify; playback seek must map segment `startMs` → file offset correctly).
  Encoder: a WASM/pure-JS Opus encoder (no native addon; must run in Electron main and Node tests).
- Recovery: on startup, scan `partial` recordings, repair/truncate to the last complete Ogg page, mark
  `partial`/`complete`, compute duration.
- `audio_recording` metadata store interface (implemented with SQLite in 2.6/desktop; an in-memory impl here)
  + paths `<base>/audio/<meeting_id>/{mic,system}.opus` (base injectable; desktop uses
  `~/Library/Application Support/Oat`).
- Decoder/reader for tests and for 2.9 backfill (`readOpusRange(path, startMs, endMs)` → PCM).
- Tests: FileSource fixture → writer → decode → duration within 1 frame, cross-correlation with source PCM
  high; kill mid-write (truncate file at random byte) → recovery yields a playable prefix; pause/overrun gaps
  keep alignment; ~20 MB/hour budget check (size per minute).
Out: playback UI (3.7), retention settings (3.8), backfill (2.9).

## Acceptance criteria
- [ ] Opus files play in standard tools (`ffprobe`/`afinfo` if available — record output) and decode in tests.
- [ ] Crash recovery test passes; alignment test passes.
- [ ] Global gates green.
