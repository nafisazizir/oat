# 1.1 — Monorepo skeleton
status: done
milestone: M1 · deps: — · branch: task/1.1-skeleton

## Goal
A pnpm + Turborepo TypeScript monorepo matching SPEC §5 layout, with shared TS/ESLint/Prettier/Vitest config,
so every later task can add code and run the global gates (`pnpm typecheck && pnpm lint && pnpm test`).

## Context
SPEC §5 (repo layout), D-11 (containerised dev — compose itself is task 1.10, not here), D-12 (local git).
Local toolchain: Node 26 (`.nvmrc` should pin 24 LTS for containers/other machines; `engines.node >=22`),
pnpm 10.34.x (`packageManager` field).

## Scope
In:
- Root: `package.json` (private, `packageManager`, scripts `build`, `dev`, `typecheck`, `lint`, `format`,
  `format:check`, `test`, `test:int`, `ci` placeholder = typecheck+lint+test), `pnpm-workspace.yaml`
  (`apps/*`, `packages/*`, `tools/*`), `turbo.json` (tasks build/typecheck/lint/test/test:int/dev with sane
  caching + `dependsOn`), `tsconfig.base.json` (strict, `noUncheckedIndexedAccess`, ES2023, `moduleResolution:
  bundler`, `verbatimModuleSyntax`), ESLint flat config (typescript-eslint, import ordering optional, no
  type-aware rules that make lint slow), Prettier config, `.editorconfig`, `.nvmrc`, `.npmrc` if needed.
- Internal packages are **TS-source packages** (`exports` → `./src/*.ts`, no build step); consumers
  (Next.js `transpilePackages`, electron-vite) compile them. Record this as a proposed decision D-15 in
  `docs/DECISIONS.md`.
- Package stubs with name `@oat/<name>`, `src/index.ts`, `tsconfig.json`, `vitest` config, and one real tiny
  test each: `packages/core`, `packages/db`, `packages/ai`, `packages/stt`, `packages/editor`, `packages/ui`.
- Vitest: per-package `test` script (`vitest run`), and `test:int` script convention (files `*.int.test.ts`,
  excluded from `test`). Packages without int tests must not fail `test:int` (use `--passWithNoTests`).
- Root `README.md` — short: what Oat is, pointer to CLAUDE.md and docs/DEV.md (to be written in 1.10).
Out: apps/web (1.4), apps/desktop (1.8), docker compose + tools/mocks (1.10), CI workflow file (1.2),
shadcn/tokens (1.3), any domain code.

## Design notes
Implementer, 2026-11-14.

**Versions** (checked with `pnpm view`, all in the pnpm `catalog:` in `pnpm-workspace.yaml`, packages use
`"catalog:"`): turbo 2.11.11, typescript 5.9.3 (latest 5.x; 7.0 exists but brief says 5.x and
typescript-eslint peers `<6.1`), vitest 5.1.0 (pulls vite 8 as auto-installed peer), eslint 10.15.0,
@eslint/js 10.0.1, typescript-eslint 8.72.2, globals 17.14.0, prettier 3.10.1, @types/node ^24 (matches
`.nvmrc` 24 LTS, not the local Node 26). `packageManager: pnpm@10.34.9`, `engines.node >=22.13` (see review fixes).

**Layout**
- Root: `package.json`, `pnpm-workspace.yaml` (apps/*, packages/*, tools/*), `turbo.json`,
  `tsconfig.base.json`, `eslint.config.js`, `vitest.shared.ts`, `.prettierrc.json`, `.prettierignore`,
  `.editorconfig`, `.nvmrc`, `README.md`. No `.npmrc` needed (no packages with blocked build scripts).
- `packages/{core,db,ai,stt,editor,ui}`: `package.json` (`@oat/<name>`, private, ESM, exports `.` →
  `./src/index.ts` and `./*` → `./src/*.ts`), `tsconfig.json` (extends base, includes `src` +
  `vitest.config.ts`), `vitest.config.ts`, `src/index.ts` (exports `packageName`), `src/index.test.ts`.
  Scripts: `typecheck: tsc`, `lint: eslint .`, `test: vitest run`, `test:int: vitest run --mode int --passWithNoTests`.

**Key choices**
- *TS-source packages* (D-15, proposed): no build step; consumers compile. `build` task exists in turbo for
  apps later; packages have no `build` script so turbo skips them.
- *tsconfig.base*: ES2023 target/lib, `module: Preserve` + `moduleResolution: bundler` (everything is
  bundled/compiled by Vite/Next/Vitest), `verbatimModuleSyntax`, `isolatedModules`, `strict`,
  `noUncheckedIndexedAccess`, `noImplicitOverride`, `noEmit`, `allowImportingTsExtensions` (lets source use
  `./x.ts` imports, which also run under Node type stripping), `jsx: react-jsx` (ui/editor will need it),
  `types: []` so no ambient @types leak in — packages opt in (e.g. `"types": ["node"]`). DOM lib is not in
  the base; ui/editor add it when they get real code (1.3).
- *Turbo*: `typecheck`/`test`/`test:int` depend on a no-op `transit` task (`dependsOn: ["^transit"]`) —
  Turbo's documented pattern for TS-source monorepos: tasks run fully in parallel, but a dependency's source
  change still invalidates dependents' caches. `lint` is independent. `test:int` and `dev` are uncached
  (`test:int` hits external services); `dev` is persistent. `globalDependencies` lists the root shared
  configs so editing them busts all caches.
- *ESLint*: one root flat config (`eslint/config` `defineConfig`), `@eslint/js` recommended +
  `typescript-eslint` recommended (non-type-aware for speed), `consistent-type-imports`, unused vars with `_`
  escape. Each package runs `eslint .`; ESLint 10 resolves the root config by walking up. The `eslint`
  binary comes from the root (pnpm puts the root `.bin` on PATH for workspace scripts), so packages only
  declare `typescript` + `vitest`. No eslint-config-prettier: none of the enabled rules are stylistic.
  Import ordering not added (optional per scope).
- *Vitest*: shared `defineOatConfig()` in root `vitest.shared.ts`, keyed on Vitest `--mode`: default mode =
  `src/**/*.test.ts` minus `*.int.test.ts`; `--mode int` = only `src/**/*.int.test.ts`. Tests import
  `describe/it/expect` explicitly (no globals). One config file per package instead of two.
- *Prettier*: printWidth 100, singleQuote, trailingComma all. `format`/`format:check` run Prettier once at
  the root (whole-repo op; routing it through turbo adds nothing and would miss root files) — a small
  deviation from "all via turbo" in the acceptance list. `docs/`, `research/`, `CLAUDE.md` are in
  `.prettierignore` so the gate does not reformat orchestrator-owned prose (avoids merge conflicts).
- *`ci` script*: `turbo run typecheck lint test && prettier --check .` (placeholder for 1.2).
  **Note for orchestrator / 1.2:** `pnpm ci` is a reserved pnpm built-in (`ERR_PNPM_CI_NOT_IMPLEMENTED`);
  the script must be invoked as `pnpm run ci`. FACTORY.md §2/§3 say `pnpm ci` — not changed here (out of scope).
- Root config files (`eslint.config.js`, `vitest.shared.ts`) are not linted (no root lint task);
  `vitest.shared.ts` is typechecked through each package's `vitest.config.ts`. Fine for now; 1.2 may add a
  root lint if wanted.

**Review round 1 fixes** (implementer, 2026-11-14), the 5 items the orchestrator relayed:
1. `vitest.shared.ts` globs now `src/**/*.test.{ts,tsx}` / `src/**/*.int.test.{ts,tsx}` (include and exclude).
   Probe: temporary `packages/ui/src/probe.test.tsx` + `probe.int.test.tsx` → unit run picked only the
   former, `--mode int` only the latter; both removed.
2. `turbo.json` `test:int` and `dev` get `passThroughEnv`: `DATABASE_URL`, `REDIS_URL`, `SMTP_*`,

   task that reads env must declare it — uncached tasks via `passThroughEnv`, *cached* tasks via `env` (so the
   value is part of the cache key). New env vars added in later tasks (1.10 etc.) must be added here.
3. `engines.node` → `>=22.13` (ESLint 10 needs `^22.13`, Vite 8 `>=22.12`).
4. D-15 now notes: Next.js needs `transpilePackages` for `@oat/*`; electron-vite must not externalize `@oat/*`
   in main/preload (bundle them) or Node will load `.ts` at runtime.
5. Package `exports` add `"./*.test": null`. Checked with Node resolution from `packages/core`:
   `@oat/core` and `@oat/core/index` → `src/index.ts`; `@oat/core/index.test` and `@oat/core/foo.int.test`
   → `ERR_PACKAGE_PATH_NOT_EXPORTED`.

## Review
Reviewer, 2026-11-14 — **verdict: `changes`** (two small fixes; everything else is sound).

Checked: diff `main...task/1.1-skeleton` + this file. Re-ran in the worktree: `pnpm install --frozen-lockfile`,
`pnpm typecheck` (incl. `--force`, 6/6), `lint`, `test`, `test:int`, `format:check` → all exit 0. Acceptance
criteria look met. turbo `transit` pattern, uncached `test:int`/`dev`, `globalDependencies`, independent `lint`,
TS-source `exports`, catalog versions and tsconfig base are all correct; no scope creep (D-15 is in scope).

Required:
1. `vitest.shared.ts:14-17` — include/exclude globs only match `.ts`, so `*.test.tsx` / `*.int.test.tsx` in
   `@oat/ui` / `@oat/editor` (React, base sets `jsx: react-jsx`) would be silently skipped by both `test` and
   `test:int`. Fix: `src/**/*.test.{ts,tsx}`, `src/**/*.int.test.{ts,tsx}` (both include and exclude).
2. `turbo.json:25-28` (`test:int`, also `dev`) — Turbo 2 runs in strict env mode by default, so undeclared env
   vars (`DATABASE_URL`, mock base URLs per D-11, provider keys) are stripped from the task's environment and
   `test:int` will fail confusingly in 1.10. Fix: add `"passThroughEnv"` to `test:int` and `dev` (e.g.
   `["DATABASE_URL", "OAT_*", ...]` or a documented wildcard), and note in D-15/DEV that cached tasks needing env
   must declare it in `env`.

Optional:
- `package.json:7` — `engines.node >=22` admits versions ESLint 10 (`^22.13`) and Vite 8 (`>=22.12`) reject;
  use `>=22.13` (or `>=24`).
- `vite` is only an auto-installed peer of vitest (8.3.8 in lockfile); add it to the catalog so electron-vite
  (1.8) and vitest share one pinned version.
- D-15: add that electron-vite's main/preload builds externalize deps by default — `@oat/*` must be excluded
  from externalization (bundled), or Node will try to load `.ts` at runtime. Worth a line for 1.8.
- `ci` script can't be run as `pnpm ci` (pnpm built-in); orchestrator should fix FACTORY §2/§3 to `pnpm run ci`
  or rename the script (e.g. `check`) in 1.2.
- `exports "./*"` also exposes test files (`@oat/core/index.test`); harmless, could narrow later.
- Root `eslint.config.js` / `vitest.shared.ts` are not linted; fine until 1.2.
