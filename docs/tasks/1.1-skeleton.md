# 1.1 — Monorepo skeleton
status: in-progress
milestone: M1 · deps: — · branch: task/1.1-skeleton

## Goal
A pnpm + Turborepo TypeScript monorepo matching SPEC §5 layout, with shared TS/ESLint/Prettier/Vitest config,
so every later task can add code and run the global gates (`pnpm typecheck && pnpm lint && pnpm test`).

## Context
SPEC §5 (repo layout), D-11 (containerised dev — compose itself is task 1.10, not here), D-12 (local git).
Local toolchain: Node 26 (`.nvmrc` should pin 24 LTS for containers/other machines; `engines.node >=22`),
pnpm 10.34.x (`packageManager` field).

## Scope
In:
- Root: `package.json` (private, `packageManager`, scripts `build`, `dev`, `typecheck`, `lint`, `format`,
  `format:check`, `test`, `test:int`, `ci` placeholder = typecheck+lint+test), `pnpm-workspace.yaml`
  (`apps/*`, `packages/*`, `tools/*`), `turbo.json` (tasks build/typecheck/lint/test/test:int/dev with sane
  caching + `dependsOn`), `tsconfig.base.json` (strict, `noUncheckedIndexedAccess`, ES2023, `moduleResolution:
  bundler`, `verbatimModuleSyntax`), ESLint flat config (typescript-eslint, import ordering optional, no
  type-aware rules that make lint slow), Prettier config, `.editorconfig`, `.nvmrc`, `.npmrc` if needed.
- Internal packages are **TS-source packages** (`exports` → `./src/*.ts`, no build step); consumers
  (Next.js `transpilePackages`, electron-vite) compile them. Record this as a proposed decision D-15 in
  `docs/DECISIONS.md`.
- Package stubs with name `@oat/<name>`, `src/index.ts`, `tsconfig.json`, `vitest` config, and one real tiny
  test each: `packages/core`, `packages/db`, `packages/ai`, `packages/stt`, `packages/editor`, `packages/ui`.
- Vitest: per-package `test` script (`vitest run`), and `test:int` script convention (files `*.int.test.ts`,
  excluded from `test`). Packages without int tests must not fail `test:int` (use `--passWithNoTests`).
- Root `README.md` — short: what Oat is, pointer to CLAUDE.md and docs/DEV.md (to be written in 1.10).
Out: apps/web (1.4), apps/desktop (1.8), docker compose + tools/mocks (1.10), CI workflow file (1.2),
shadcn/tokens (1.3), any domain code.

## Acceptance criteria
- [ ] `pnpm install` works from a clean clone (lockfile committed).
- [ ] `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm test:int`, `pnpm format:check` all exit 0 via turbo.
- [ ] A deliberate type error in any package makes `pnpm typecheck` fail (verify, then revert).
- [ ] Adding a new package under `packages/` is picked up by turbo with no root config change.
- [ ] D-15 entry added.

## Verification
```
rm -rf node_modules && pnpm install --frozen-lockfile
pnpm typecheck && pnpm lint && pnpm test && pnpm test:int && pnpm format:check
pnpm turbo run test --dry=json | head -50   # lists all 6 packages
```
