# 7.3 — Meeting notes from calendar events (+ detection wiring)
status: in-progress
milestone: M7 · deps: 3.4, 7.1, 7.2, 7.4 · branch: task/7.3-calendar-notes

## Goal
Upcoming meetings are one click from notes: the desktop shows today's events, "Start notes" creates a meeting note
pre-filled from the event (title, time, attendees as participants, conference link), and meeting detection's
"Start notes?" prompt does the same for the current event.

## Context
SPEC §3.1 (Detect), §4 Calendar/Detection, D-21, `@oat/calendar` (CalendarSource, SidecarCalendarSource fixture
mode, GoogleCalendarSource via web API `/api/calendar/upcoming`), `@oat/core` calendar helpers
(currentMeetingFor, startingSoon), `@oat/detection` (Detector, MicAppsSource fixture/sidecar), `apps/desktop`
(meeting view 3.4, RecordingService, notifications), `apps/web` Home "Upcoming" (7.4).

## Scope
In:
- Desktop: "Upcoming" list in the sidebar (today + tomorrow; from EventKit via sidecar when permitted, else
  Google via web API, merged/deduped); event → "Start notes" creates the meeting doc with title, start time,
  calendar_event_id, participants (calendar source), conference link in header; joining an already-created note
  for the same event reopens it (no duplicates).
- Detection wiring: run `Detector` in main (MicAppsSource sidecar in prod, fixture in dev/e2e via env); on
  `prompt` show a native notification + in-app banner "Start notes for <event or app>?" → creates/opens the note
  and starts recording; "Not now" / silence app; respects D-21 rules; `meetingStarting` notification ~1 min
  before events with attendees (startingSoon).
- Web Home "Upcoming": "Start notes" creates the meeting note on web (no recording) with the same prefill.
- Permissions UX: if Calendars permission not granted, a clear "Connect calendar" call-to-action (sidecar status) —
  never prompt automatically.
- Tests: unit (dedupe/merge, prefill mapping), desktop e2e with calendar fixture + mic-apps fixture timeline →
  notification banner appears → accept → note created with attendees + recording running (FileSource);
  web e2e Start notes from Upcoming. Screenshots.
Never run real EventKit / mic-apps / capture — fixtures only.

## Acceptance criteria
- [ ] Event → note prefill works on desktop + web; detection prompt creates the note and starts recording (fixtures).
- [ ] `pnpm run ci` green.
