# 4.5 + 4.6 — Regenerate / switch template / versions & undo + "About me"
status: in-progress
milestone: M4 · deps: 4.4 · branch: task/4.5-regenerate-versions

## Goal
Control over AI notes: regenerate (same or different template), see and restore earlier enhancement
versions, view my original notes, undo an enhancement — and an "About me" profile that enhancement and chat
use as context.

## Context
SPEC §4 Enhance, §7, D-20, D-26, `apps/web` enhance API/UI (4.4: enhancement rows with input_notes_json,
output_json, applied flag; "Use enhanced version"), `@oat/ai` (`buildMeetingContext` takes `aboutMe`; chat uses
it too), `@oat/db` (enhancement table; user profile — add `user_profile` table or column via migration,
renumber after main's latest).

## Scope
In:
- Versions: list enhancements for a document (time, template, applied); "View" read-only; "Restore" sets the
  document body to that version (new document version, baseVersion check); "Show my original notes" (from
  the latest input_notes_json); "Undo enhancement" = restore the body to the input notes of the last run.
- Regenerate: same template or pick another; warn (confirm dialog) when the current body differs from the
  last output (user edited AI notes) — D-20.
- About me: `/settings/profile` — name/role/team/what I care about/terms & names to spell correctly (max length,
  plain text); stored per user; passed into `buildMeetingContext` (fenced as data) for enhance and chat;
  vocabulary also offered to STT as keyterms (D-17) via the token route response (optional).
- Authz + deny markers for new routes; int tests (restore at stale version → 409, viewer can't restore, other
  user's profile inaccessible); e2e: enhance → edit → regenerate with warning → restore v1 → undo; profile
  saved and visible in the enhance prompt (mock echo). Screenshots.
Out: auto-enhance (7.5).

## Acceptance criteria
- [ ] Versions/restore/undo/regenerate work; about-me flows into context; `pnpm run ci` + eval green.
