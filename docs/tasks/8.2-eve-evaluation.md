# 8.2 — eve evaluation: spike a post-meeting agent, decide
status: in-progress
milestone: M8 · deps: 6.2 · branch: task/8.2-eve-evaluation

## Goal
Decide (D-7 follow-up) how durable/background agents run: eve vs AI SDK + a workflow/queue we already have.
Produce a working spike of the post-meeting pipeline in the chosen approach and a DECISIONS entry proposal.

## Context
D-7 (interactive = AI SDK tool loop; durable = eve, decided here after reading eve's bundled docs), D-11
(dev must run fully offline in containers — hard constraint), D-13, D-22 (change_log worker + Redis queue from
6.1), D-26 (enhance job), `packages/ai/tools` (plain functions reusable by eve), PLAN 8.3 (post-meeting pipeline:
enhance → action items → push to integrations). Load the `eve` / `vercel:eve` skill and read eve's docs from
`node_modules` after installing it in a scratch package — do not rely on memory.

## Scope
In:
- Install eve into a scratch workspace package `agents/` (or `packages/agents`), read its bundled docs; answer
  in Design notes: can it run locally/offline with our mock LLM (OpenAI-compatible base URL) and our Postgres/
  Redis? what infra does durability need (Vercel Workflow? local dev server?)? how are tools/connections
  defined? scheduling? observability? cost/lock-in?
- Spike: `post-meeting` agent that, given a meeting id, (1) runs enhance if not done (reusing our enhance job),
  (2) ensures action items are indexed, (3) pushes to Notion if the workspace has auto-push configured (mock),
  (4) records a run log — implemented in the most promising approach; if eve can't run offline, implement it
  on our Redis queue/worker (6.1) + AI SDK and document why.
- Compare in a table: eve vs our worker (durability, retries, local dev, testing, ops, lock-in) and propose
  D-29 (or next free number) text.
- Tests: spike has an int test against the compose stack + mocks (no network).
Out: production pipeline wiring/triggers (8.3).

## Acceptance criteria
- [ ] Design notes answer the questions with evidence (doc excerpts paraphrased, commands run).
- [ ] Spike runs offline end-to-end in a test; decision proposal written.
- [ ] `pnpm run ci` green.
