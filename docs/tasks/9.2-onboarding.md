(microphone, system audio, calendar — each explained, requested only on the user's click) → test recording →
first meeting guide; plus the 9.3 pass applied to every desktop screen.

## Context

## Scope
In:
- Onboarding (desktop, first run per account; re-openable from Settings → "Setup"): steps with status read from
  the sidecar (`permissions`, `calendar status` — never prompting automatically); each "Allow" button triggers
  the request command (in e2e: fixture/synthetic mode only, permission state injected); "Test recording" runs a
  10 s capture (synthetic in e2e) showing levels for Me/Them and a live transcript line; "Connect Google
  Calendar" opens the web integrations page; finish → first-meeting guide card (how notes + transcript +
  enhance work), dismissible.
- Desktop design pass: screenshot sweep of every desktop screen light/dark, punch list in Design notes, fixes
  (tokens only), axe scan of renderer routes in desktop e2e (0 serious/critical), 9.3b tickets done.
- Tests: onboarding unit (step state machine from permission states), desktop e2e (fresh profile → onboarding
  → synthetic test recording → finish; denied permission shows how to fix in System Settings with a deep link
  `x-apple.systempreferences:` — opened via shell.openExternal, mocked in e2e). Screenshots.
NEVER trigger real permission prompts or real capture in tests.
