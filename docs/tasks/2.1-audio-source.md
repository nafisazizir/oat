# 2.1 — `AudioSource` interface + `FileSource` + fixtures
status: todo
milestone: M2 · deps: 1.1 · branch: task/2.1-audio-source

## Goal
The abstraction that makes capture testable without a microphone: one `AudioSource` interface for live
(sidecar) and file-based audio, plus realistic two-voice meeting fixtures.

## Context
SPEC §3, §5 (AudioSource), §6 (shared clock with segments), FACTORY §4, D-8. Frame format must match the
sidecar's wire protocol: `native/oat-audio/PROTOCOL.md` (task 2.3, may be merged already — if not, the
model is: frames tagged `source: 'mic'|'system'`, `tUs` microseconds on one shared clock, PCM s16le mono 16 kHz).

## Scope
In:
- New package `packages/audio` (`@oat/audio`): types `AudioFrame {source, tUs, pcm: Int16Array, sampleRate}`,
  `AudioEvent`, `AudioSource` (start/stop/pause/resume, `frames()` async iterable or event emitter — pick and
  justify; must support backpressure-free fan-out to STT + archive writer), `FileSource` (reads a 2-channel
  WAV where L=mic, R=system, or two mono WAVs; speeds `realtime` | `fast` | factor; resamples to 16 kHz mono
  if needed; emits ~20 ms frames per source with correct timestamps; pause/resume honoured).
  WAV parse/write utilities (no native deps). Level/RMS helper.
- Fixture generator `packages/audio/scripts/make-fixtures.ts`: uses macOS `say` (two different voices for
  me/them) + `afconvert` to build short scripted meetings from a JSON script (`fixtures/audio/<name>.json`:
  list of `{speaker: me|them, text, gapMs}`); output `fixtures/audio/<name>.wav` (2-ch 16 kHz s16) and a
  `<name>.segments.json` with ground-truth `{source, startMs, endMs, text}` (used by FakeSttProvider in 2.2
  and evals later). Generate and commit 2–3 fixtures: `standup-short` (~30 s), `one-on-one` (~60–90 s),
  `silence-gap` (with a 10 s silence to test resilience). Keep each WAV < 3 MB. Script must no-op gracefully
  on non-macOS (fixtures are committed).
- Tests: WAV round-trip, FileSource timing (fast mode), frame sizes, pause/resume, ground-truth alignment.
Out: SidecarSource (2.4), STT (2.2), Opus (2.8).

## Acceptance criteria
- [ ] FileSource on `standup-short.wav` in `fast` mode emits frames for both sources whose total duration
      matches the file within 1 frame; timestamps monotonic per source; same clock across sources.
- [ ] `realtime` mode takes ~real time (test with a 1 s slice).
- [ ] Fixtures + ground-truth JSON committed; regenerating is deterministic in text/timings.
- [ ] Global gates green.
