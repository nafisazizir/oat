# 4.2 — Eval harness + fixture meetings
status: in-progress
milestone: M4 · deps: 4.1 · branch: task/4.2-evals

## Goal
A repeatable way to tell whether AI changes (enhancement now, chat later) got better or worse, runnable offline
against the mock (structural tier) and with a real model when a key is set (quality tier) — D-13.

## Context
SPEC §7 (Evals), FACTORY §3 (`pnpm --filter @oat/ai eval` must not regress vs main), D-13, D-20 (enhancement
output model: sections → blocks with origin; templates = title/description/ordered sections). `@oat/ai`
(getModel, mock models, Output.object). `fixtures/audio/*.segments.json` (3 short meetings with ground truth).
`research/granola/enhance-chat.md` (behaviour reference only — no prompts copied).

## Scope
In:
- `packages/ai/evals/`: fixture meetings (≥ 5, synthetic, written by us): each `{ meta (title, attendees,
  started_at), template id, myNotes (Markdown, rough), transcript segments (source, startMs, endMs, text),
  expectations }`. Reuse the 3 audio fixtures' ground truth as transcripts for 3 of them; write 2 longer
  text-only ones (sales discovery, interview). Expectations are *properties*, not golden text: must-mention
  facts/decisions/action items (with owner), must-not-hallucinate list (names/numbers not in transcript),
  my-notes coverage (every user note line represented, origin=me), section headings from template present,
  length bounds.
- Harness: `pnpm --filter @oat/ai eval [--suite enhance] [--model real|mock] [--json out.json]`: runs a
  pluggable `task(fixture) → output` (enhance task stub for now: a placeholder function in packages/ai that 4.4
  will replace — keep the interface), scores with
  - structural checks (schema valid, headings, origin marking, length) — always;
  - property checks via deterministic string/regex matching where possible;
  - LLM-as-judge checks (grounding, coverage) only in `--model real` (skipped with a clear notice otherwise),
  writes a results table + JSON; compares to a committed baseline `evals/baseline.json` and exits non-zero on
  regression beyond a tolerance. `eval:baseline` script to update it.
- Unit tests for scorers.
Out: real enhancement prompt (4.4), chat evals (6.5).

## Acceptance criteria
- [ ] `pnpm --filter @oat/ai eval` runs offline against the mock and prints a table; structural tier passes
      for the stub; baseline committed; regression detection proven by a test.
- [ ] Quality tier is cleanly skipped without a key.
- [ ] Global gates green.
